# -
Fukuoka travel planner

매일 작업하는 순서 (3명 모두, 제일 중요!)

작업할 때마다 이 4단계만 순서대로 반복하면 돼요.

🔽 ① 작업 시작 전: 최신 내용 받기 (Pull)
GitHub Desktop 위쪽의 Fetch origin 클릭
버튼이 Pull origin으로 바뀌면 한 번 더 클릭

⚠️ 이걸 깜빡하는 게 문제의 90%예요. 작업 전에는 꼭 Pull 하세요.

✏️ ② 작업하기
Open in Visual Studio Code 버튼을 누르거나, 평소처럼 폴더를 열어서 코드를 수정하고 저장(Ctrl+S)합니다.
GitHub Desktop 왼쪽에 바뀐 파일 목록이 자동으로 떠요.
💾 ③ 기록하기 (Commit)
왼쪽 아래 Summary 칸에 무엇을 했는지 짧게 적어요.
예: 카드 화면 디자인 수정, 버튼 클릭 기능 추가
Commit to main 버튼 클릭
🔼 ④ 올리기 (Push)
위쪽의 Push origin 클릭

확인: github.com 저장소에 들어가 보면 내가 고친 내용이 올라가 있어요. 다른 팀원은 ①번(Pull)을 하면 받을 수 있어요.
